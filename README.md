# 🧠 ML-CS — Machine Learning Credit Scoring
# Autor: Davi Bezerra Fraga  

# Tecnologias: Python 3.11.4 • Pandas • Scikit-learn • Jupyter Notebook

## 📌 Visão Geral

Este projeto implementa um modelo de **Machine Learning** supervisionado para Credit Scoring, com foco em avaliar o risco de crédito de clientes e prever a probabilidade de inadimplência.

---

## 📊 Fonte dos dados:

Dataset público obtido na plataforma **Kaggle**

O projeto simula um cenário real do setor financeiro, utilizado por bancos e fintechs, e demonstra um pipeline completo de Machine Learning, do início ao fim.

---

## 🎯 Objetivos do Projeto

* Automatizar a análise de risco de crédito
* Reduzir subjetividade na concessão de crédito
* Identificar padrões relevantes nos dados
* Demonstrar habilidades práticas em Data Science e ML


---

## 🔁 Pipeline de Machine Learning

### 1️⃣ Aquisição dos Dados
* `Dataset público do Kaggle`
* `Arquivos utilizados:`
 
                * tabelatreinamento.csv — dados para treino
                * tabeladenovosclientes.csv — dados para previsão

### 2️⃣ Análise Exploratória dos Dados (EDA)
* `Análise da estrutura dos dados`
* `Identificação de padrões e inconsistências`
* `Entendimento das variáveis relevantes`

### 3️⃣ Pré-processamento
* `Tratamento de variáveis categóricas`
* `Codificação para modelos supervisionados`
* `Definição de:`
 
                * Features (variáveis independentes)
                * Target (score de crédito)

### 4️⃣ Divisão dos Dados
* `70% treino`
* `30% teste`
* `Avaliação imparcial do modelo`
  
### 5️⃣ Modelagem
* `Algoritmo utilizado:`
 
                * Random Forest Classifier
* `Escolhido pela robustez e bom desempenho em classificação`

### 6️⃣ Avaliação do Modelo
* `Cálculo da acurácia`
* `Análise do desempenho geral`

### 7️⃣ Interpretação dos Resultados
* `Análise da importância das variáveis`
* `Identificação dos fatores mais relevantes no score`

### 8️⃣ Aplicação em Novos Clientes
* `Previsões realizadas com:`

                * tabeladenovosclientes.csv

* `Simulação de uso em ambiente real`
